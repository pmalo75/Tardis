# Tardis
*A prediction model for the SNCF railway service*

## Installation
> This part only covers Linux installation.

We suggest to use a virtual environment.

You can run your python executable with the following arguments : `-m venv ./venv`.

Then, using the binaries inside your environment, set the env source using `source ./venv/Scripts/activate`

Now, you're ready to install the dependencies.
Use the following command to install: `pip3 install -r requirements.txt`.
